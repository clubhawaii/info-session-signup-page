# 소장님 설명회 신청 페이지

원장님이 소장님 1명을 고르고 희망 날짜 1~3순위(시간 포함)를 보내면, 소장님이 알림톡 링크에서 그중 하루를 확정하거나 「조율 필요」를 누르는 페이지입니다. 결제는 받지 않고, 확정 뒤 본사가 결제를 안내합니다. 모든 데이터는 구글시트에 쌓입니다.

## 흐름

1. **원장님** — `index.html`: 소장님 선택 → 희망 날짜 3개 + 시작 시간 → 신청 정보 → 신청
2. **알림톡 3곳**
   - 원장님: 신청 완료 · 소장님이 일정 확인 중 · 확정되면 연락드림
   - 소장님: 학원·지역·대상·인원·요청사항·희망 날짜 3개 + 응답 링크 + "3일 안에 고르지 않으면 자동 취소, 기회는 다른 소장님께"
   - 본사: 새 신청 전체 내용
3. **소장님** — `coach.html?t=…`(알림톡 링크): 1·2·3순위 중 하나 확정, 또는 「세 날짜 모두 어려워요(조율 필요)」
   - 확정 → 시트 상태 `일정확정`, 「예약불가」에 자동 추가, 환불 마감일·결제 안내 문구 자동 생성, 본사 알림
   - 조율 필요 → 상태 `조율 필요`, 소장님 메모와 함께 본사 알림 → 본사가 직접 조율
4. **3일(72시간) 안에 응답이 없으면** 1시간마다 도는 자동 점검이 상태를 `기한 만료`로 바꾸고 본사에 알림 → 본사가 다른 소장님 배정

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` · `styles.css` · `app.js` | 원장님 신청 페이지 (PC·모바일) |
| `coach.html` | 소장님 응답 페이지 (알림톡 링크로 열림) |
| `config.js` | **오픈 전에 고칠 설정** — Apps Script 주소, 문의 링크, 개인정보 보관 기간, 가격, 시간 선택지 |
| `sample-data.js` | 시트 연결 전 미리보기용 예시 데이터 |
| `apps-script/Code.gs` | 구글시트 스크립트 (저장·알림톡·소장님 응답·기한 만료·자동 차단) |

`config.js`의 `APPS_SCRIPT_URL`이 비어 있으면 **시험 모드**로 열립니다(예시 데이터, 저장 안 됨, 상단에 안내 띠). 파일을 더블클릭해서 바로 볼 수 있습니다.

## 구글시트 연결 (처음 한 번)

1. 새 구글시트를 만듭니다. (공개 공유하지 말고 담당자 계정에만 편집 권한)
2. **확장 프로그램 → Apps Script**를 열고 기본 코드를 지운 뒤 `apps-script/Code.gs` 내용을 붙여 넣습니다.
   - 맨 위 `HQ_PHONES`(본사 알림톡 받을 번호), `HQ_EMAIL`(본사 메일), `COACH_PAGE_URL`(배포 주소 + `coach.html`)을 채웁니다.
3. 함수 선택에서 `setupSheets` → **실행** → 권한 승인.
   「신청내역」「소장님」「예약불가」「알림기록」 시트, 상태 드롭다운, 편집 자동 처리·1시간 자동 점검 트리거가 만들어집니다.
4. **배포 → 새 배포 → 웹 앱** (실행: 나, 액세스: 모든 사용자) → 나온 `…/exec` 주소를 `config.js`의 `APPS_SCRIPT_URL`에 넣습니다.
   스크립트를 고친 뒤에는 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.

## 알림톡 연결

`Code.gs`는 **솔라피(SOLAPI)** 기준으로 만들어 두었습니다. 다른 업체를 쓰면 `notify_` 함수만 바꾸면 됩니다.

1. 카카오 비즈니스 채널을 솔라피에 연동하고, `Code.gs` 위쪽 `TEMPLATES`의 문구 6개를 **그대로** 템플릿으로 등록해 검수받습니다.
   (`DIRECTOR_RECEIVED` 원장님 신청 완료 · `COACH_REQUEST` 소장님 일정 확인 요청 · `HQ_NEW` · `HQ_CONFIRMED` · `HQ_ADJUST` · `HQ_EXPIRED` 본사용)
2. Apps Script **⚙ 프로젝트 설정 → 스크립트 속성**에 넣습니다:
   `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SOLAPI_PFID`, `SOLAPI_FROM`, `TPL_DIRECTOR_RECEIVED` … `TPL_HQ_EXPIRED`(검수된 템플릿 ID)
3. 설정 전에는 알림톡을 보내지 않고 「알림기록」 시트에 "미발송(설정 전)"으로 실제 보낼 문구만 남깁니다 — 이걸로 흐름을 먼저 시험할 수 있습니다.

## 시트 입력 방법

**「소장님」** — `노출`이 `Y`인 소장님만 페이지에 나옵니다. `연락처`는 알림톡 발송에만 쓰이고 페이지에는 나가지 않습니다.
- `대상 태그`: 쉼표 구분 — 초등 학부모, 중등 학부모, 고등 학부모, 초등학생, 중학생, 고등학생 (이 글자 그대로)
- `설명회 주제`: 셀 안 줄바꿈(Ctrl+Enter)으로 여러 개 · `진행 지역`: 예) 서울·경기
- `강의 영상 URL`: 유튜브 일부공개 링크 · 사진 URL: 구글 드라이브 링크 가능("링크가 있는 모든 사용자 보기")

**「예약불가」** — 여기 있는 소장님·날짜는 달력에서 막힙니다. 개인 일정은 직접 한 줄 추가합니다.

**「신청내역」** — 신청 1건이 1줄입니다.
- 상태: `소장님 확인중` → `일정확정` / `조율 필요` / `기한 만료` → `결제안내` → `결제완료` → `진행완료` (또는 `취소`)
- `조율 필요`·`기한 만료` 줄은 파랗게 표시됩니다 — 본사가 처리할 건입니다.
- 조율 후 본사가 직접 확정할 때: `확정일`(+확정 시간) 입력 → 상태를 `일정확정`으로. 그날 이미 예약이 있으면 경고 후 되돌립니다.
- `금액`·`출장비`를 넣으면 환불 마감일 3개와 **결제 안내 문구**가 자동으로 만들어집니다. (결제 금액 = 금액 + 출장비)
- 상태를 `취소`나 `기한 만료`로 바꾸면 「예약불가」의 확정 줄이 자동으로 지워집니다.

## 오픈 전 확정할 것

- [ ] 알림톡 업체·카카오 채널·템플릿 검수
- [ ] 본사 알림 받을 번호·메일 → `Code.gs`
- [ ] 소장님 정보·연락처 → 「소장님」 시트
- [ ] 출장비 기준·금액
- [ ] 개인정보 보관 기간 → `config.js`의 `PRIVACY_RETENTION`
- [ ] 문의 채널 링크 → `config.js`의 `CONTACT_URL`
