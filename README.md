# 강연자 설명회 신청 페이지

원장님이 희망 날짜 1~3순위와 강연자 1~3순위, 설명회 종류·주제를 골라 신청하면, 본사 담당자가 강연자와 일정을 조율해 3일 안에 원장님께 연락하는 페이지입니다. 결제는 받지 않고, 모든 데이터는 구글시트에 쌓입니다.

## 흐름

1. **원장님** — `index.html`: 희망 날짜 3개(+시작 시간) → 강연자 3명(순서대로) → 설명회 종류·주제 → 신청 정보 → 신청
   - 「1순위 강연자를 꼭 희망합니다(강연자 일정에 따라 날짜 조정 가능)」 체크 가능
2. **본사 알림톡** (담당자·이사님·대표님): 새 신청 전체 내용. 원장님께는 알림톡을 보내지 않습니다(완료 화면에서 "3일 안에 담당자 연락" 안내).
3. **담당자** — 시트에서 신청 줄을 누르고 메뉴 **설명회 → 선택한 신청의 강연자에게 확인 요청** → 순위(1·2·3) 또는 강연자 이름 입력
   - 강연자에게 알림톡(응답 링크 + "24시간 안에 응답하지 않으면 기회는 다른 강연자께") 발송, 상태 `강연자 확인중`
4. **강연자** — `coach.html?t=…`: 가능한 날짜 선택 / 날짜 조율 필요 / 진행 불가 → 본사 알림톡
   - 24시간 안에 응답이 없으면 1시간마다 도는 점검이 `응답 없음`으로 바꾸고 본사에 알림 → 담당자가 3번으로 차순위 강연자에게 다시 요청
5. **담당자**가 원장님께 직접 확정 연락(단톡방 개설) → 상태 `일정확정` → 「예약불가」에 자동 추가
6. 상태 `결제안내`로 바꾸면 **결제 기한**(24시간, 주말이면 월요일로)이 자동으로 들어가고, 지나면 본사에 알림

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` · `styles.css` · `app.js` | 원장님 신청 페이지 (PC·모바일) |
| `coach.html` | 강연자 응답 페이지 (알림톡 링크로 열림) |
| `config.js` | **오픈 전에 고칠 설정** — Apps Script 주소, 카카오 채널 주소, 설명회 종류·가격, 출장비, 맞춤 주제 |
| `sample-data.js` | 시트 연결 전 미리보기용 예시 데이터 |
| `apps-script/Code.gs` | 구글시트 스크립트 (저장·알림톡·강연자 요청/응답·기한 점검·자동 차단) |
| `미리보기.bat` | 내 컴퓨터에서 미리 보기 (저장소에는 안 올림) |

`config.js`의 `APPS_SCRIPT_URL`이 비어 있으면 **시험 모드**입니다(예시 데이터, 저장 안 됨). 주소 검색은 파일을 더블클릭해 열면 동작하지 않으니 `미리보기.bat`으로 여세요.

## 구글시트 연결 (처음 한 번)

1. 새 구글시트를 만듭니다. (공개 공유하지 말고 담당자 계정에만 편집 권한)
2. **확장 프로그램 → Apps Script**에 `apps-script/Code.gs` 내용을 붙여 넣고, 맨 위 `HQ`(담당자·이사님·대표님 번호), `HQ_EMAIL`, `COACH_PAGE_URL`을 채웁니다.
3. 함수 `setupSheets` **실행** → 권한 승인. 「신청내역」「강연자」「예약불가」「알림기록」 시트와 상태 드롭다운, 자동 처리 트리거가 만들어집니다. 시트를 새로고침하면 「설명회」 메뉴가 생깁니다.
4. **배포 → 새 배포 → 웹 앱** (실행: 나, 액세스: 모든 사용자) → `…/exec` 주소를 `config.js`의 `APPS_SCRIPT_URL`에 넣습니다. 스크립트를 고치면 **배포 관리 → 수정 → 새 버전**.

## 알림톡 연결 (솔라피 기준)

1. `Code.gs`의 `TEMPLATES` 문구 7개를 **그대로** 카카오 템플릿으로 등록해 검수받습니다.
   `HQ_NEW` 새 신청 · `COACH_REQUEST` 강연자 확인 요청 · `HQ_ACCEPTED` 강연자 수락 · `HQ_ADJUST` 날짜 조율 · `HQ_DECLINED` 진행 불가 · `HQ_NO_RESPONSE` 응답 없음 · `HQ_PAY_OVERDUE` 결제 기한 지남
2. Apps Script **⚙ 프로젝트 설정 → 스크립트 속성**: `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SOLAPI_PFID`, `SOLAPI_FROM`, `TPL_…`(템플릿 ID 7개)
3. 설정 전에는 보내지 않고 「알림기록」에 "미발송(설정 전)"으로 문구만 남깁니다.

## 시트 입력 방법

**「강연자」** — `노출`이 `Y`인 강연자만 페이지에 나옵니다. `연락처`는 알림톡에만 쓰이고 페이지에 나가지 않습니다. `설명회 주제`(셀 안 줄바꿈으로 여러 개)는 원장님이 「대표 주제 설명회」를 고를 때 주제 선택지가 됩니다.

**「예약불가」** — 여기 있는 강연자·날짜는 강연자 카드에 "이미 일정이 있어요"로 표시되고, 강연자 응답 때 그 날짜는 고를 수 없습니다.

**「신청내역」 상태**
`접수` → `강연자 확인중` → `강연자 수락` / `조율 필요` / `강연자 불가` / `응답 없음` → `일정확정` → `결제안내` → `결제완료` → `진행완료` (또는 `취소`)
- 파란 줄 = 본사가 다음 행동을 할 차례 (접수·수락·조율·불가·응답 없음)
- `일정확정`은 `확정 강연자`·`확정일`이 있어야 바뀝니다(강연자가 수락하면 자동으로 채워짐). 그날 이미 예약이 있으면 경고 후 되돌립니다.
- `금액`·`출장비`를 넣으면 환불 마감일 3개와 결제 안내 문구가 자동으로 만들어집니다.
- `취소`로 바꾸면 「예약불가」의 확정 줄이 지워져 날짜가 다시 열립니다.
