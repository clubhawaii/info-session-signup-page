# 소장님 설명회 신청 페이지

원장님이 설명회를 진행할 소장님(여러 명 가능)과 희망 일정(1~3순위)을 골라 신청하는 페이지입니다.
결제는 받지 않고 신청만 받으며, 담당자가 연락해 일정 확인 후 결제를 안내합니다. 기획서: `설명회_신청페이지_기획서.md`(내부 문서라 저장소에는 올리지 않음)

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` · `styles.css` · `app.js` | 페이지 (정적 HTML, 서버 필요 없음) |
| `config.js` | **오픈 전에 고칠 설정** — Apps Script 주소, 문의 링크, 개인정보 보관 기간, 가격 |
| `sample-data.js` | 시트를 연결하기 전 미리보기용 예시 데이터 |
| `apps-script/Code.gs` | 구글시트에 붙이는 스크립트 (신청 저장·데이터 제공·메일·자동 차단) |

`config.js`의 `APPS_SCRIPT_URL`이 비어 있으면 **시험 모드**로 열립니다(예시 데이터 표시, 신청은 저장되지 않음, 상단에 노란 띠).

## 구글시트 연결 (처음 한 번)

1. 새 구글시트를 만듭니다. (공개 공유하지 말고 담당자 계정에만 편집 권한)
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 열고, 기본 코드를 지운 뒤 `apps-script/Code.gs` 내용을 붙여 넣습니다.
   - 맨 위 `NOTIFY_EMAIL`에 담당자 알림 메일 주소를 넣습니다.
3. 편집기 위쪽 함수 선택에서 `setupSheets`를 골라 **실행** → 권한 승인.
   - 「신청내역」「소장님」「예약불가」「월별추천」「공휴일」 시트와 상태 드롭다운, 연락 기한 초과 빨간 표시, 편집 자동 처리 트리거가 만들어집니다.
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자로 실행: **나**, 액세스 권한: **모든 사용자**
   - 배포 후 나오는 `https://script.google.com/macros/s/…/exec` 주소를 `config.js`의 `APPS_SCRIPT_URL`에 넣습니다.
   - 스크립트를 고친 뒤에는 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다(주소는 그대로).

## 시트 입력 방법

**「소장님」** — `노출`이 `Y`인 소장님만 페이지에 나옵니다.
- `대상 태그`: 쉼표로 구분 — 초등 학부모, 중등 학부모, 고등 학부모, 초등학생, 중학생, 고등학생 (이 글자 그대로)
- `목적 태그`: 쉼표로 구분. 여기 적은 값들이 「질문으로 추천받기」 2번 질문의 선택지가 됩니다.
- `설명회 주제`: 셀 안에서 줄바꿈(Ctrl+Enter)으로 여러 개
- `강의 영상 URL`: 유튜브 일부공개 링크
- `프로필 사진 URL` · `사진 샘플 URL`(쉼표 구분): 구글 드라이브 링크도 됩니다(파일을 "링크가 있는 모든 사용자 보기"로 공유).

**「예약불가」** — 여기 있는 소장님·날짜는 달력에서 막힙니다. 개인 일정은 직접 한 줄 추가합니다.

**「월별추천」** — `월`(1~12), `추천 테마`, `설명`, `추천 대상`, `추천 소장님`(쉼표 구분, 「소장님」 시트 이름과 똑같이)

**「공휴일」** — 연락 기한(영업일 3일) 계산에서 뺄 날짜

**「신청내역」 처리 순서**
1. 신청이 들어오면 소장님 1명당 1줄로 쌓이고, 상태는 `접수`, 연락 기한이 자동으로 들어갑니다.
2. 같은 소장님·같은 희망일로 `접수`/`소장님 확인중`인 신청이 겹치면 희망일 칸이 노랗게 표시됩니다.
3. `확정일`(+확정 시간)을 입력하고 상태를 `일정확정`으로 바꾸면 「예약불가」에 자동으로 추가됩니다.
   이미 그 소장님이 그날 예약돼 있으면 경고창이 뜨고 상태가 되돌아갑니다.
4. `금액`(설명회 비용)과 `출장비`를 입력하면 환불 마감일 3개와 **결제 안내 문구**가 자동으로 만들어집니다. 결제 금액 = 금액 + 출장비.
5. 상태를 `취소`로 바꾸면 「예약불가」에서 해당 줄이 자동으로 지워집니다.

## 오픈 전 확정할 것 (기획서 13번)

- [ ] 출장비 기준·금액
- [ ] 소장님 상세 정보 + 목적 태그 → 「소장님」 시트
- [ ] 월별 추천 내용 → 「월별추천」 시트
- [ ] 개인정보 보관 기간 → `config.js`의 `PRIVACY_RETENTION`
- [ ] 문의 채널 링크 → `config.js`의 `CONTACT_URL`
- [ ] 담당자 알림 메일 → `Code.gs`의 `NOTIFY_EMAIL`
