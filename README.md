# 강연자 설명회 신청 페이지

원장님이 소장님(여러 명)과 소장님별 설명회 하나, 희망 날짜 하나·시작 시간을 골라 신청하면, 고른 소장님께 각각 출강 요청 알림톡이 가고 소장님이 24시간 안에 직접 답하는 페이지입니다. 결과는 원장님께 알림톡 한 통으로 모아서 보내고, 원장님이 한 분을 고르면 담당자가 확정·결제를 안내합니다. 결제는 받지 않고, 모든 데이터는 구글시트에 쌓입니다.

## 흐름

1. **원장님** — `index.html`: 소장님(여러 명, 제한 없음) → 소장님별 설명회 하나 → 희망 날짜 하나 + 시작 시간(10분 단위) + 요청사항 → 신청 정보 → 신청
   - 요청사항은 "담당자가 확인한 뒤 연락드립니다" 안내. 시트 「요청사항 확인」 체크칸으로 처리 여부 표시
   - 확정된 일정과 시작 시간 앞뒤 3시간(`OVERLAP_HOURS`) 안이 겹치는 소장님은 신청할 수 없음(빼거나 시간을 바꾸라고 안내)
2. **자동 발송** — 신청이 시트에 저장되면 바로
   - **소장님마다 출강 요청 알림톡**(`COACH_REQUEST`): 응답 링크 + "기한(24시간) 안에 응답이 없으면 원장님께 「불가」로 안내". 「소장님 응답」 시트에 소장님마다 한 줄
   - **원장님 접수 알림톡**(`DIRECTOR_RECEIVED`): 응답 기한과 "결과를 한 번에 보내 드립니다" 안내
   - **본사 알림톡**(`HQ_NEW`): 새 신청 전체 내용
3. **소장님** — `coach.html?t=…`: 「가능 / 시간 조율 필요(가능한 시간 필수) / 불가」. 같은 날 다른 일정(확정·대기 중 요청)이 보이고, 앞뒤 3시간 안이면 빨갛게 "시간이 겹쳐요" — 판단은 소장님
   - 마감 6시간(`REMIND_HOURS`) 전까지 답이 없으면 독촉 알림톡(`COACH_REMIND`) 한 번
   - 기한이 지나면 「응답 없음(불가)」 (15분마다 점검)
4. **결과 안내** — 모든 소장님이 답하거나 기한이 지나면 원장님께 한 통으로
   - 가능·시간 조율이 한 명이라도 있으면 `DIRECTOR_RESULT` + 선택 링크(`choose.html?t=…`), 없으면 `DIRECTOR_NONE`(담당자가 연락). 본사에도 `HQ_RESULT`
5. **원장님** — `choose.html`: 가능·시간 조율 소장님 중 한 분 선택 → 상태 `원장님 선택 완료`, 선택된 소장님 `COACH_CHOSEN`, 나머지 가능·조율 소장님 `COACH_RELEASED`, 본사 `HQ_CHOSEN`
6. **담당자**가 원장님께 확정 연락 → 상태 `일정확정` → 「예약불가」에 날짜·시작 시간 자동 추가 → 그 시간 앞뒤 3시간은 다른 원장님이 그 소장님을 신청할 수 없음
7. 상태 `결제안내`로 바꾸면 **결제 기한**(24시간, 주말이면 월요일로)이 자동으로 들어가고, 지나면 본사에 알림
8. 가능한 소장님이 없을 때 등: 신청 줄을 누르고 메뉴 **설명회 → 선택한 신청에 소장님 추가 요청** → 「이름 / 설명회」 입력(새 기한 24시간, 답이 모이면 결과를 다시 보냄)

### 강연자 정보 받기 (`profile.html`)

1. 소장님께 `…/profile.html` 주소를 보냅니다. 「강연자」 시트의 `연락처`와 같은 휴대폰 번호로 들어옵니다.
2. 브랜딩 이미지를 토대로 정리한 슬로건·경력과 대표 주제가 미리 채워져 있고(브랜딩 이미지 자체는 보여 주지 않음, `클럽하와이 직함`은 경력 맨 위 고정 줄로 보이고 소장님은 못 고침), 소장님은 바꿀 부분만 고칩니다. 링크(구분+주소, 유튜브는 소개 페이지에서 바로 재생)·사진(드라이브 「강연자 사진/이름」 폴더에 자동 저장)을 넣습니다. **프로필 사진·대표 주제 1~5개·웹 게시 동의는 필수**, 「배치되면 우선 수락」 동의는 선택입니다. 대표 주제 카테고리는 여러 개 고를 수 있고 맞는 게 없으면 「기타」로 직접 적습니다.
3. 제출하면 「프로필 제출」에 한 줄이 쌓입니다(`바뀐 항목`·`변경 내용`에 「전 → 후」로 정리). 반영 전에 다시 제출하면 같은 줄이 새 내용으로 바뀝니다.
4. 본사가 확인 후 그 줄을 고르고 메뉴 **설명회 → 선택한 프로필 제출을 강연자 정보에 반영** → 「강연자」·「대표 주제」가 바뀌고 신청 페이지에 바로 보입니다.
5. 대표 주제의 `영역`이 비즈니스 교육(강사·조직원 교육 / 원장 경영 교육 / 단체·연합회 특강)이면 이 신청 페이지에는 나오지 않습니다. 나중에 열 비즈니스 페이지용입니다(`config.js`의 `AREAS`).

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` · `styles.css` · `app.js` | 원장님 신청 페이지 (PC·모바일) |
| `coach.html` | 소장님 응답 페이지 (알림톡 링크로 열림) |
| `choose.html` | 원장님 결과·소장님 선택 페이지 (결과 알림톡 링크로 열림) |
| `profile.html` · `profile.css` · `profile.js` | 강연자 정보 입력 페이지 (소장님이 번호로 들어와 소개·대표 주제를 고쳐 제출) |
| `config.js` | **오픈 전에 고칠 설정** — Apps Script 주소, 카카오 채널 주소, 설명회 종류·가격, 출장비, 맞춤 주제 |
| `sample-data.js` | 시트 연결 전 미리보기용 예시 데이터 |
| `seed/` · `local-data.js` | 실제 강연자 초기 자료(브랜딩 이미지 문구·예전 컨시어지 시트) — **저장소에 올리지 않음**. `seed/build_seed.py`를 실행하면 `seed/강연자_초기자료.xlsx`(시트에 붙여 넣을 표)와 내 컴퓨터 미리보기용 `local-data.js`가 만들어집니다 |
| `apps-script/Code.gs` | 구글시트 스크립트 (저장·알림톡·강연자 요청/응답·기한 점검·자동 차단) |
| `미리보기.bat` | 내 컴퓨터에서 미리 보기 (저장소에는 안 올림) |

`config.js`의 `APPS_SCRIPT_URL`이 비어 있으면 **시험 모드**입니다(예시 데이터, 저장 안 됨). 주소 검색은 파일을 더블클릭해 열면 동작하지 않으니 `미리보기.bat`으로 여세요.

## 구글시트 연결 (처음 한 번)

1. 새 구글시트를 만듭니다. (공개 공유하지 말고 담당자 계정에만 편집 권한)
2. **확장 프로그램 → Apps Script**에 `apps-script/Code.gs` 내용을 붙여 넣고, 맨 위 `HQ`(담당자·이사님·대표님 번호), `HQ_EMAIL`, `COACH_PAGE_URL`을 채웁니다.
3. 함수 `setupSheets` **실행** → 권한 승인(사진 저장용 드라이브 권한 포함). 「신청내역」「강연자」「대표 주제」「프로필 제출」「예약불가」「알림기록」 시트와 상태 드롭다운, 자동 처리 트리거가 만들어집니다. 시트를 새로고침하면 「설명회」 메뉴가 생깁니다.
4. Apps Script에 `seed/Seed.gs`(내 컴퓨터에만 있음, 소장님 연락처 포함)를 새 파일로 추가하고 `importSeed`를 **실행**하면 「강연자」·「대표 주제」가 채워집니다. (직접 붙여 넣으려면 `seed/강연자_초기자료.xlsx`의 두 탭을 2행부터 붙여 넣어도 됩니다. 연락처 칸은 입력 페이지 로그인 번호)
5. **배포 → 새 배포 → 웹 앱** (실행: 나, 액세스: 모든 사용자) → `…/exec` 주소를 `config.js`의 `APPS_SCRIPT_URL`에 넣습니다. 스크립트를 고치면 **배포 관리 → 수정 → 새 버전**.

## 알림톡 연결 (솔라피 기준)

1. `Code.gs`의 `TEMPLATES` 문구 11개를 **그대로** 카카오 템플릿으로 등록해 검수받습니다.
   원장님: `DIRECTOR_RECEIVED` 접수 · `DIRECTOR_RESULT` 결과(선택 링크) · `DIRECTOR_NONE` 가능한 소장님 없음
   소장님: `COACH_REQUEST` 출강 요청 · `COACH_REMIND` 마감 전 독촉 · `COACH_CHOSEN` 선택됨 · `COACH_RELEASED` 다른 소장님으로 진행
   본사: `HQ_NEW` 새 신청 · `HQ_RESULT` 결과 안내함 · `HQ_CHOSEN` 원장님 선택 · `HQ_PAY_OVERDUE` 결제 기한 지남
2. Apps Script **⚙ 프로젝트 설정 → 스크립트 속성**: `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SOLAPI_PFID`, `SOLAPI_FROM`, `TPL_…`(템플릿 ID 11개, 예: `TPL_COACH_REQUEST`)
3. 설정 전에는 보내지 않고 「알림기록」에 "미발송(설정 전)"으로 문구만 남깁니다.

## 시트 입력 방법

**「강연자」** — `노출`이 `Y`인 강연자만 페이지에 나옵니다. `연락처`는 알림톡과 입력 페이지 로그인에만 쓰이고 페이지에 나가지 않습니다. `슬로건`은 한 줄(50자 미만), `경력`은 셀 안 줄바꿈으로 한 줄에 하나씩(자격·저서·방송도 여기에), `클럽하와이 직함`은 경력 맨 위에 붙어 보이고 소장님은 못 고침, `관련 링크`는 한 줄에 `구분 | 주소`. 카드에는 슬로건이, 상세에는 슬로건·경력·대표 주제·영상·링크·사진이 나옵니다. `우선 수락 동의`는 소장님이 체크한 값(Y/N)입니다.

**「대표 주제」** (= 소장님 설명회 상품) — 소장님 한 명당 여러 줄(`순서`대로). `주제명`이 설명회 이름이며 원장님이 소장님을 고른 뒤 이 중 하나를 고릅니다. 대상·지역·전문 분야가 드러나게(예: 경기지역 특성화고 고입설명회). `카테고리`(쉼표로 여러 개)는 「주제로 찾기」, `대상`은 대상 필터가 됩니다. `노출`을 `N`으로 하면 숨깁니다.

**「소장님 응답」** — 신청 한 건에 고른 소장님 수만큼 줄이 생깁니다. `응답`: `응답 대기` → `가능` / `시간 조율 필요` / `불가` / `응답 없음(불가)` → (원장님 선택 후) `원장님이 선택` / `다른 소장님으로 진행`.

**「예약불가」** — `시작 시간`이 있으면 그 시간 앞뒤 3시간, 비어 있으면 그날 하루 전체가 막힙니다. 원장님 신청 화면에서 겹치는 소장님은 신청할 수 없습니다.

**「신청내역」 상태**
`소장님 응답 대기` → `원장님 선택 대기` / `가능한 소장님 없음` → `원장님 선택 완료` → `일정확정` → `결제안내` → `결제완료` → `진행완료` (또는 `취소`)
- 파란 줄 = 본사가 다음 행동을 할 차례 (원장님 선택 완료 · 가능한 소장님 없음)
- `응답 현황`에 소장님별 응답·메모가 모입니다.
- `일정확정`은 `확정 강연자`·`확정일`이 있어야 바뀝니다(원장님이 고르면 자동으로 채워짐, 시간 조율이면 `확정 시간`을 고쳐 주세요). 확정 일정과 겹치면 경고 후 되돌립니다.
- `금액`·`출장비`를 넣으면 환불 마감일 3개와 결제 안내 문구가 자동으로 만들어집니다.
- `취소`로 바꾸면 「예약불가」의 확정 줄이 지워져 시간이 다시 열립니다.
- **이미 예전 스크립트로 `setupSheets`를 실행했다면** 「신청내역」「예약불가」 탭을 지우고(머리글만 있을 때) 다시 실행해 주세요. 머리글이 바뀌었습니다.
