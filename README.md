# 강연자 설명회 신청 페이지

원장님이 소장님(최대 3명)과 소장님별 설명회 하나, 희망 날짜 하나·시작 시간을 골라 신청하면, 고른 소장님께 각각 출강 요청 알림톡이 가고 소장님이 24시간 안에 「가능 / 시간 조율 필요 / 불가」로 답하는 페이지입니다. 응답은 본사 담당자에게 모이고, **원장님은 신청할 때 말고는 본사 담당자와 직접 조율**합니다. 결제는 받지 않고, 모든 데이터는 구글시트에 쌓입니다.

## 흐름

1. **원장님** — `index.html`: 소장님(최대 3명, `MAX_PICKS`) → 소장님별 설명회 하나 → 희망 날짜 하나 + 시작 시간(10분 단위) + 요청사항 → 신청 정보 → 신청
   - 화면에 "고르신 소장님들께 일정이 되는지 먼저 확인하고, 가능한 소장님만 정리해 담당자가 연락드립니다" 안내
   - 요청사항은 "담당자가 확인한 뒤 연락드립니다" 안내. 시트 「요청사항 확인」 체크칸으로 처리 여부 표시
   - 확정된 일정과 시작 시간 앞뒤 3시간(`OVERLAP_HOURS`) 안이 겹치는 소장님은 신청할 수 없음
2. **자동 발송** — 신청이 시트에 저장되면 바로
   - **소장님마다 출강 요청 알림톡**(`COACH_REQUEST`): 응답 링크 + "밤·주말 포함 24시간 안에 응답, 없으면 「불가」 처리" + "한 번 보낸 응답은 바꿀 수 없음". 「소장님 응답」 시트에 소장님마다 한 줄
   - 「강연자」 시트에 연락처가 없는 소장님은 요청을 보내지 못하므로 바로 「불가」(메모 「연락처가 없어 요청을 보내지 못함」)
   - **원장님 접수 알림톡**(`DIRECTOR_RECEIVED`): "일정 확인 후 담당자가 최대한 빠르게 연락드립니다"
   - **본사 알림**(`HQ_NEW`): 새 신청 전체 내용
3. **소장님** — `coach.html?t=…`: 「가능 / 시간 조율 필요(가능한 시간 필수) / 불가」. 같은 날 다른 일정(확정·대기 중 요청)이 보이고, 앞뒤 3시간 안이면 빨갛게 "시간이 겹쳐요" (판단은 소장님)
   - **가능·시간 조율 응답은 그때마다 바로 본사에**(`HQ_ANSWER`, 지금까지의 응답 현황 포함)
   - 마감 6시간(`REMIND_HOURS`) 전까지 답이 없으면 독촉 알림톡(`COACH_REMIND`) 한 번
   - 기한이 지나면 「응답 없음(불가)」 (15분마다 점검)
4. **응답 마감** — 모든 소장님이 답하거나 기한이 지나면 본사에 마감 알림(`HQ_RESULT`) → 상태 `본사 조율 중` 또는 `가능한 소장님 없음`
5. **담당자** — 가능한 소장님·원장님과 직접 조율 (마감을 기다리지 않고 가능 응답이 오는 대로 진행해도 됨)
6. **확정·결제 안내** — 「신청내역」에 `확정 강연자`·`확정일`·`확정 시간`·`금액`(+`출장비`)을 넣고, 그 줄을 누른 채 메뉴 **설명회 → 선택한 신청 확정·결제 안내 보내기**
   - 보낼 문구를 미리 보여 주고 「예」를 누르면 발송
   - 원장님: `DIRECTOR_CONFIRMED` (확정 일정·결제 금액·결제 기한·결제 방법·환불 규정)
   - 확정 소장님: `COACH_CONFIRMED` / 가능·조율이라고 했던 다른 소장님: `COACH_RELEASED` (다른 소장님으로 진행, 정중한 감사 인사) / 아직 응답 전인 소장님: `COACH_CLOSED` (요청 마감)
   - 상태 `결제안내`, 결제 기한(24시간, 주말이면 월요일로) 자동 입력, 「예약불가」에 그 시간 추가. 결제 기한이 지나면 본사 알림(`HQ_PAY_OVERDUE`)
   - 다시 실행하면 원장님께만 다시 보냅니다(소장님들께는 한 번만)
7. 가능한 소장님이 없을 때 등: 신청 줄을 누르고 메뉴 **설명회 → 선택한 신청에 소장님 추가 요청** → 「이름 / 설명회」 입력 → 그 소장님께 `COACH_REQUEST`(새 기한 24시간). 응답이 오면 위와 같이 본사로. 날짜·시간을 바꿔 요청하려면 먼저 「희망일」·「시작 시간」 칸을 고친 뒤 실행
8. 결제를 확인하면 상태 `결제완료`, 끝나면 `진행완료`

### 강연자 정보 받기 (`profile.html`)

1. 소장님께 `…/profile.html` 주소를 보냅니다. 「강연자」 시트의 `연락처`와 같은 휴대폰 번호로 들어옵니다.
2. 브랜딩 이미지를 토대로 정리한 슬로건·경력과 설명회가 미리 채워져 있고(`클럽하와이 직함`은 경력 맨 위 고정 줄로 보이고 소장님은 못 고침), 소장님은 바꿀 부분만 고칩니다. 링크·사진(드라이브 「강연자 사진/이름」 폴더에 자동 저장)을 넣습니다. **링크 기준**: 클럽하와이 유튜브(https://www.youtube.com/@ISYOUHAWAII)와 클럽하와이 블로그(https://blog.naver.com/isyou0943)에 있는 **소장님 본인 영상·글만** 받습니다(영상·글 하나의 주소). 다른 채널·블로그(개인 채널 포함), 다른 회사 로고가 나오는 영상·글은 안 됩니다. 유튜브는 입력 페이지와 시트 스크립트가 그 영상의 채널을 자동으로 확인하고(유튜브 oEmbed), 블로그는 주소가 isyou0943의 글인지 확인합니다. 본인 영상·글인지는 본사가 반영 전에 확인합니다. 원장님 화면에도 기준 밖 링크는 보이지 않습니다. **프로필 사진·설명회 1개 이상(개수 제한 없음)·웹 게시 동의는 필수**입니다.
3. 제출하면 「프로필 제출」에 한 줄(상태 `확인 대기`)이 쌓이고 **본사에 알림**(`HQ_PROFILE`)이 갑니다. `바뀐 항목`·`변경 내용`에 「전 → 후」로 정리됩니다. 반영 전에 다시 제출하면 같은 줄이 새 내용으로 바뀝니다. 소장님 화면에는 "바로 보이지 않고 본사 확인 후 반영" 안내가 나옵니다.
4. 담당자가 그 줄을 고르고 메뉴 **설명회 → 선택한 프로필 제출을 강연자 정보에 반영** → 「강연자」·「설명회」가 **소장님이 마지막으로 제출한 내용 그대로** 바뀌고 신청 페이지에 바로 보입니다. 상태는 `반영 완료`, `반영일시`가 찍힙니다. 더 최근 제출이 있는 옛 줄은 반영할 수 없습니다.
5. 설명회의 `영역`이 비즈니스 교육(강사·조직원 교육 / 원장 경영 교육 / 단체·연합회 특강)이면 이 신청 페이지에는 나오지 않습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` · `styles.css` · `app.js` | 원장님 신청 페이지 (PC·모바일) |
| `coach.html` | 소장님 응답 페이지 (알림톡 링크로 열림) |
| `profile.html` · `profile.css` · `profile.js` | 강연자 정보 입력 페이지 (소장님이 번호로 들어와 소개·설명회를 고쳐 제출) |
| `config.js` | **오픈 전에 고칠 설정** — Apps Script 주소, 카카오 채널 주소, 가격, 출장비, 최대 선택 인원 |
| `sample-data.js` | 시트 연결 전 미리보기용 예시 데이터 |
| `seed/` · `local-data.js` | 실제 강연자 초기 자료 — **저장소에 올리지 않음** |
| `apps-script/Code.gs` | 구글시트 스크립트 (저장·알림톡·응답 기한 점검·확정 안내·자동 차단) |
| `미리보기.bat` | 내 컴퓨터에서 미리 보기 (저장소에는 안 올림) |

`config.js`의 `APPS_SCRIPT_URL`이 비어 있으면 **시험 모드**입니다(예시 데이터, 저장 안 됨). 주소 검색은 파일을 더블클릭해 열면 동작하지 않으니 `미리보기.bat`으로 여세요.

## 구글시트 연결 (처음 한 번)

1. 새 구글시트를 만듭니다. (공개 공유하지 말고 담당자 계정에만 편집 권한)
2. **확장 프로그램 → Apps Script**에 `apps-script/Code.gs` 내용을 붙여 넣습니다.
3. Apps Script **⚙ 프로젝트 설정 → 시간대**를 **(GMT+09:00) 서울**로 바꿉니다. (응답 기한·결제 기한 시각이 이 시간대로 계산됩니다)
4. 함수 `setupSheets` **실행** → 권한 승인. 「신청내역」「소장님 응답」「강연자」「설명회」「프로필 제출」「예약불가」「본사 알림」「설정」「알림기록」 시트와 트리거가 만들어지고, 시트 시간대도 서울로 맞춰집니다. 스크립트 시간대가 서울이 아니면 안내 창이 뜹니다.
5. **「본사 알림」** 시트에 알림 받을 사람의 `휴대폰`(알림톡)·`메일`을 적습니다. 한 줄에 한 사람, 둘 중 하나만 있어도 됩니다. 비어 있으면 본사 알림은 「알림기록」에만 남습니다.
6. **「설정」** 시트의 `결제 방법` 값을 적습니다(예: 계좌이체 ○○은행 …). 확정·결제 안내 알림톡에 들어갑니다.
7. Apps Script에 `seed/Seed.gs`(내 컴퓨터에만 있음, 소장님 연락처 포함)를 새 파일로 추가하고 `importSeed`를 **실행**하면 「강연자」·「설명회」가 채워집니다.
8. **배포 → 새 배포 → 웹 앱** (실행: 나, 액세스: 모든 사용자) → `…/exec` 주소를 `config.js`의 `APPS_SCRIPT_URL`에 넣습니다. 스크립트를 고치면 **배포 관리 → 수정 → 새 버전**.

## 알림톡 연결 (솔라피 기준)

1. `Code.gs`의 `TEMPLATES` 문구 12개를 **그대로** 카카오 템플릿으로 등록해 검수받습니다.
   원장님: `DIRECTOR_RECEIVED` 접수 · `DIRECTOR_CONFIRMED` 확정·결제 안내
   소장님: `COACH_REQUEST` 출강 요청 · `COACH_REMIND` 마감 전 독촉 · `COACH_CONFIRMED` 확정 · `COACH_RELEASED` 다른 소장님으로 진행 · `COACH_CLOSED` 요청 마감(응답 전)
   본사: `HQ_NEW` 새 신청 · `HQ_ANSWER` 가능·조율 응답 · `HQ_RESULT` 응답 마감 · `HQ_PROFILE` 소장님 정보 제출 · `HQ_PAY_OVERDUE` 결제 기한 지남
2. Apps Script **⚙ 프로젝트 설정 → 스크립트 속성**: `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SOLAPI_PFID`, `SOLAPI_FROM`, `TPL_…`(템플릿 ID 12개, 예: `TPL_COACH_REQUEST`)
3. 설정 전에는 보내지 않고 「알림기록」에 "미발송(설정 전)"으로 문구만 남깁니다.

## 시트 입력 방법

**「강연자」** — `노출`이 `Y`인 강연자만 페이지에 나옵니다. `연락처`는 알림톡과 입력 페이지 로그인에만 쓰이고 페이지에 나가지 않습니다(여러 개면 쉼표·줄바꿈, 알림은 첫 번호로). `슬로건`은 한 줄(50자 미만), `경력`은 셀 안 줄바꿈으로 한 줄에 하나씩, `클럽하와이 직함`은 경력 맨 위에 붙어 보이고 소장님은 못 고침, `관련 링크`는 한 줄에 `구분 | 주소`.

**「설명회」** (= 소장님 설명회 상품) — 소장님 한 명당 여러 줄(`순서`대로). 원장님이 소장님을 고른 뒤 `설명회 이름` 중 하나를 고릅니다. 대상·지역·전문 분야가 드러나게(예: 경기지역 특성화고 고입설명회). `카테고리`(쉼표로 여러 개)는 「주제로 찾기」, `대상`은 대상 필터가 됩니다. `노출`을 `N`으로 하면 숨기지만, 소장님 제출을 반영하면 제출 내용 그대로 다시 `Y`가 됩니다.

**「소장님 응답」** — 신청 한 건에 고른 소장님 수만큼 줄이 생깁니다. `응답`: `응답 대기` → `가능` / `시간 조율 필요` / `불가` / `응답 없음(불가)` → (확정 안내 후) `확정` / `다른 소장님으로 진행`. 소장님은 한 번 답하면 바꿀 수 없으니, 바꿔 달라는 연락이 오면 담당자가 이 칸을 직접 고칩니다(직접 고친 값으로는 알림이 나가지 않음).

**「예약불가」** — `시작 시간`이 있으면 그 시간 앞뒤 3시간, 비어 있으면 그날 하루 전체가 막힙니다. 소장님 개인 일정은 직접 한 줄 넣으면 됩니다.

**「신청내역」 상태**
`소장님 응답 대기` → `본사 조율 중` / `가능한 소장님 없음` → `결제안내`(확정·결제 안내 보냄) → `결제완료` → `진행완료` (또는 `취소`)
- 파란 줄 = 본사가 다음 행동을 할 차례 (본사 조율 중 · 가능한 소장님 없음)
- `응답 현황`에 소장님별 응답·메모가 모입니다.
- `금액`·`출장비`를 넣으면 환불 마감일 3개와 결제 안내 문구가 자동으로 만들어집니다.
- 알림톡 없이 시간만 막으려면 상태를 직접 `일정확정`으로 바꿉니다(`확정 강연자`·`확정일` 필요, 겹치면 경고 후 되돌림).
- `취소`로 바꾸면 「예약불가」의 확정 줄이 지워져 시간이 다시 열립니다. 원장님·소장님 연락은 담당자가 직접 합니다.
- **이미 예전 스크립트로 `setupSheets`를 실행했다면** 「신청내역」「소장님 응답」 탭을 지우고(머리글만 있을 때), 「대표 주제」 탭 이름을 「설명회」로, 그 탭의 `주제명` 머리글을 `설명회 이름`으로 바꾼 뒤 다시 실행해 주세요.
